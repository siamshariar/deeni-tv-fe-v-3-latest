# Android Local Offline - Build & Deployment Guide

## Quick Start

### Prerequisites
```bash
# Node/pnpm environment
pnpm --version

# Java/Gradle for Android
java -version
./android/gradlew --version

# Capacitor CLI
npm install -g @capacitor/cli
```

### Build Steps

> **Corrected during PR #21 review**: `next export` as a standalone command
> was removed in Next.js 13.3+/14 — running it on this project (Next.js
> 16.0.10) fails immediately with "`next export` has been removed in favor
> of `output: export` in next.config.js", verified by actually running it.
> The real build step is the `build:android-web` script already defined in
> `package.json`, shown below.

1. **Build the static `out/` directory for Android**
   ```bash
   cd deeni-tv-fe
   pnpm run build:android-web
   # Runs `pnpm build` (Next.js server build), then copies public/, the
   # prerendered index.html, and .next/static/ into out/ — see the script
   # definition in package.json for the exact steps.
   ```

2. **Sync web assets to Android**
   ```bash
   npx cap sync android
   # Copies 'out' directory contents to android/app/src/main/assets/public/
   ```

3. **Build Android APK** (offline-capable)
   ```bash
   cd android
   ./gradlew assembleRelease  # or assembleDebug for testing
   # Output: android/app/build/outputs/apk/release/app-release.apk
   ```

## On Android Device

1. App starts with Capacitor loading files from `assets/public/`
2. Channel list displays from embedded `CHANNELS` data
3. Video playback:
   - **With Internet**: Fetches live schedule from API
   - **No Internet**: Uses embedded Bengali channel (6 videos)
   - **Graceful Fallback**: Never shows blank screen

## Customization

### Update Embedded Schedule
Edit `public/api/fallback-schedule.json` to add more channels or programs:
```json
{
  "channels": [
    {
      "id": "channel-id",
      "name": "Channel Name",
      "programs": [
        {
          "id": "video-1",
          "videoId": "youtube-id",
          "title": "Video Title",
          "duration": 3600,
          ...
        }
      ]
    }
  ]
}
```

Then rebuild and redeploy.

### Add More Fallback Programs
1. Edit `lib/schedule-utils.ts` - add to `BENGALI_VIDEOS` array
2. Or update `public/api/fallback-schedule.json` directly
3. Rebuild APK to include new data

## Performance Notes

- **First Load**: ~2-3s (faster than remote API)
- **Offline Startup**: Instant (no network timeout)
- **Battery**: Reduced (no repeated API polling when offline)
- **Storage**: ~5-10 MB added (static files + schedule JSON)

## Troubleshooting

**Issue**: App shows blank screen on Android
- Check: `android/app/src/main/assets/public/` exists
- Run: `npx cap sync android` again
- Rebuild: `./gradlew assembleRelease`

**Issue**: Local schedule not loading
- Check: `/api/fallback-schedule.json` exists in APK
- Verify: `fetch('/api/fallback-schedule.json')` succeeds in Android Chrome DevTools
- Ensure: `pnpm run build:android-web` ran successfully

**Issue**: Channels still showing spinner on Android
- Check network connectivity first
- Verify embedded data in `lib/schedule-utils.ts` CHANNELS
- Check browser console for fetch errors
